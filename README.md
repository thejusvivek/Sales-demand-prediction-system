# Product Sales Demand Prediction & Classification System

A complete machine learning pipeline built to forecast sales revenue and classify product demand using real-world retail data.

## 🚀 Project Overview
This project solves two core business challenges for retail inventory management:
1. **Sales Revenue Prediction (Linear Regression):** Forecasts exact monetary sales values based on order quantities and pricing.
2. **Demand Classification (Logistic Regression):** Classifies whether a product order falls into "High Demand" or "Low Demand" categories based on performance benchmarks.

## 🛠️ Tech Stack & Libraries
* **Language:** Python
* **Data Manipulation:** Pandas, NumPy
* **Machine Learning:** Scikit-Learn (Linear Regression, Logistic Regression, Train-Test Split, Metrics)
* **Model Serialization:** Pickle (`.pkl`)
* **Environment:** Google Colab, VS Code

## 📊 Results & Performance
* **Linear Regression:** Successfully captured sales variance based on order traits.
* **Logistic Regression:** Achieved an **Accuracy Score of over 92%** in identifying high vs. low demand product orders.
